# 逐句语义配图与独立镜头审核

“属于同一朝代”不等于“说明了这句话”。先读真实口播和证据层级，再决定画什么，最后才找或生成素材。不能从一个朝代素材池里轮播。

若项目有《历史图片素材规范》《历史视频素材规范》及visual-policy/visual-review-template，先按其检查表与评分要求执行。现有辅助脚本不能自动证明逐项语义、原生来源、真实全幅或完整动作检查通过。

## 先写看懂什么

每个镜头至少有：确切帧区间、原cueIds、narration原句、visualGoal、matchReason、artDirection、evidenceClass、visualFamily与素材记录。当前字段和脚本见 [独立镜头契约](single-shot-contract.md)。

实际审核绑定素材SHA、当前正文和语义快照，包含对应来源主张与参考关系；改变配用的句子、证据层级或画面目标后，不能仅因图片哈希相同沿用旧审核。缺失evidenceClass或visualFamily等项要补齐，不能以当前脚本没有报错作为豁免。

选择最能表达当前信息的视觉形式：

- 具体行动：人物、手和物件的一次变化；
- 空间：真实有依据的地点/路径，已知与推测的路线分开；
- 权力关系/因果：简单的关系或物件图，不把图表画成历史上的真实共同会面；
- 争议：证物与来源空缺、不同解释并列，不能替观众定案；
- 失去机会或否定命题：空席、未拆信、停住的路线等，但含义必须对应本句；
- 抽象判断：优先清楚的图片视觉隐喻，只有准确结构/动作必须靠代码时才做局部结构合成，不自动降级成文字卡片。

简单物件/行动通常3–5秒，关系解释4–7秒，空间交代/情绪沉淀6–9秒。按真实语句和信息密度调整；长镜头必须有理由，不能拿同一幅静图延长来覆盖一整段。这是编辑起点，不是普适的留存实验结论。

## 正式资产只用独立全幅

一张正式图只包含一个连贯的目标画幅画面（新项目默认横屏16:9）。一张已审图只给对应的一个图生视频任务。禁止正式四格、拼图、故事板联系表及其局部放大；QC联系表应保存在独立目录，不能被素材清单引用。

结构图可以在同一空间比较两种关系或几项因素，但每项都要读得清且有解释目的；这不授权把四个完整场景缩小塞进一张图。

图片生成提示词骨架：

图像生成按本片锁定的通道小批推进，每个正式镜头独立调用。项目有统一风格包与 image_style_pipeline 时，先按其完成所需格式和参考条件的校准，使用编译后的真实请求，不把下面的通用骨架当作绕过冻结入口的快捷方式。遵守服务并发与共享队列要求；不通过一次“四格生成”偷换为四个正式镜头。已有符合本片要求的资产先复核复用其唯一镜头位置，不重付费生成。

```text
用途：一个历史解释视频的独立全幅镜头；目标画幅按项目锁定，默认横屏16:9。
风格：按本片已确认方向；默认连续暖白底、清楚炭笔/刻线和克制水彩。不要撕纸装饰边、卷角、粘贴纸片和外框；叙事需要的书页/奏疏可作为道具。
本句口播及证据层级：……
观众应看懂：……
唯一主体与必要对象：……
空间/动作：A在左、B在右；朝向……；开始状态……；结束状态……
人物与道具连续性：本片已审参考……，仅作为身份参考，不复制旧构图。
排除：不符合本句的事件、人物、年代道具、生成文字、无关标题、Logo、水印。
底部约14%相对安静，留给后期字幕。
```

不要固定把某朝代的衣服、君主年龄、木偶、符节等写进跨主题默认提示词。为本片建立角色/物件表，对“不要出现某人”的负面排除避免在另一个CAST字段把他重新加回。

## 看实际像素，不看成功状态

生成/下载后仅登记pending。接受前逐项对照：

1. 主体是不是本句谈到的人、物、地点或关系，是否提前出场；
2. 动作方向是否反了：离城不能朝门内走，关门不能留一半敞开，最后倒下不能画成第一块触发；
3. 数量、年代、服饰、年龄、材质、代际关系是否误导；
4. 否定、假设、传闻、梦境、后世解释有没有被画成已发生的事实；
5. 是否新增与口播无关的证物、旁观者、假字、现代器物、署名或水印；
6. 手机上主体、结构和关键道具能否读清；字幕安全区是否够；
7. 是否与其他镜头出现机械重复，而没有新的信息或构图。

为每次accepted/rejected写具体观察，不写“看起来不错”作为唯一证据。修复要另存版本，保留旧来源、请求和原因。模型输出分辨率低时不以放大冒充原生清晰度。

项目规定分项评测时逐项填写，不只给总分；未实际查看当前图片不评分，旧图得分不移给新文件。原生尺寸要能追溯到原件和取得记录，不能把经过放大的文件重新登记为原生。

## 去重的正确尺度

- 同一实际图/视频、其裁切、改色或重编码版本不重复使用。
- 哈希检查实际文件；derivedFromSourceId记录同一原始来源。不同文件名不能绕过去重。
- 感知哈希仅筛近似候选，不能自动证明语义合格。
- 同一人物、竹简、城门等广义visualFamily可为新信息再次出现；必须有新的视角、动作、证据状态或关系，用独立构图表达。
- 把一张军阵照换成另一张军阵照，却仍与当前句子无关，仍然不合格。
- 有意首尾照应也用新镜头与新的叙事视角，不重播原文件。

## 网络素材

只为明确的视觉缺口搜索。保留检索词、来源页面、作者、年代、许可、下载时间、原生尺寸及修改记录。元数据筛选后还要看图；标题正确但像素会误导的候选照样拒绝。

真实史料/遗物、后世画像、当代遗址、复原图与普通同类器物必须区分。“同代同类”要披露不是该事件原物；后世画像不冒充当时写真。网上找到不意味着可商用，不调用生成图冒充原始证据。不复用影视长片段作未获许可的主要画面。

## 视频结果再验一次

获用户批准并生成后，抽取首、中、尾及关键动作帧核对：参考图是否真正生效、动作是否只执行一次、有没有人脸/人数/物件漂移、镜头方向/边界是否正确、有无四格和新文字。错误片段不因为“花过钱”就入片。重生成也走视频确认关卡。

此外查看完整使用区间，或用连续逐帧检查覆盖动作过程，以核对中间闪烁、跳变、穿模、冻结及循环。只看关键帧须标注抽查范围，不可填全段运动检查通过。实际请求与生效模型/提示词/参考图应有核验记录，未取得的字段如实保留未知。

没有实际看图与视频帧时，不得只凭提示词或状态success标为accepted。自动技术检查通过也不是史实或语义的自动背书。
