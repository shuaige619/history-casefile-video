# 影视记忆与史料翻转

当用户希望用熟知影视剧、小说或课文建立“我知道的是这样，真实材料却更离谱”的认知落差时使用。目标不是挑错影视作品，而是借观众已有记忆，更快说明历史问题为什么值得追查。

若项目有《历史认知反差与影视对照规范》，优先执行其必做流程和记录契约。先区分候选发现、具体情节核验、史料对照、正文采用四层；只核分集文本就如实标文本核验，不称实际看过或听过。作品如何呈现不能自动代表所有观众怎么想。

## 先判断值不值得用

影视桥梁适合进入开头的第二层，须同时满足：

- 作品与本片的核心事件、人物或选择直接相关，不只是朝代相同；
- 作品的具体表达能够从正片、官方物料或可靠分集梗概中核对；
- 一句话能说清观众可能记得什么，随后立即给出有史料依据的反差；
- 没看过作品的观众仍能听懂历史异常和主问题；
- 对比带来的是因果或证据翻转，不只是服装、年龄、选角等猎奇纠错。

作品认知度、对应强度或实际剧情不能确认时，不把“大家都知道”写进稿子，也不为追热点强行使用。开头最多放一个作品；其他桥梁留到相关人物或事件首次发挥作用时。历史评书不得以作品名、演员或集数作为第一句，除非交付物本身是在评论这部作品。

## 双层核验与证据标记

对比必须拆成两条互不替代的证据链：

1. **作品表达链**：实际查看正片、官方剧情页或可靠分集梗概，记录剧名、集数/场景位置、角色、剧情大意和URL。该来源在`source-ledger.json`中标为`screen_reference`。
2. **历史判断链**：重新查一手史料、接近事件时代的记录及可靠研究，区分事实、引文、解释和争议，不用影视来源替历史结论背书。

脚本中，影视剧情、合成人物和改编关系用D标记，表示明确披露的戏剧参照；历史事实、引文与解释仍分别使用F、Q、I。不要把同时包含影视剧情和史实反转的整段统一标成F。最稳妥的写法是拆成相邻两段：D段只说作品怎样表达，F/Q/I段立即说明史料留下了什么。

影视来源只能证明“作品这样拍”，不能证明“历史就是这样”。二手剧情梗概只能支持梗概实际覆盖的内容；没有核到具体情节时，继续找可核材料并保持待核，不能泛化成“这类影视叙事常把……”绕过证据。项目要求具体对照时，未核不能作为“不用且完成”的理由。

## 开头结构

优先使用这一短链：

`评书报题 → 白话解题 → 最小背景与异常结果 → 点名一部熟知作品与一个具体记忆 → 明确这是影视表达 → 用一条史料细节翻转 → 解释翻转改变了什么判断 → 抛出本片核心问题`

控制原则：

- 开头直接用本题人物身份／事件关系、具体行动或有据异常形成钩子，让陌生听众听懂基本内容；不强制第一句读标题、第二句解题的固定顺序。标题不代替理解，不以影视名替代史实说明；
- 报题、解题后再补大致时代、人物局面和异常结果；只给理解钩子必需的背景，不念百科；
- 作品名和记忆锚点在事件可懂后尽早出现，但不先做演员、角色或剧情简介；
- 从点名作品起约20—30秒内说出“影视如此表达，史料却留下另一层问题”；
- 30—60秒开始兑现第一条史料反差，不能把“真实历史更离谱”空悬到后文；
- 对比只揭示已知结果与证据缺口，不提前讲完全部答案；
- 开头删除作品名后仍应成立；若删除后观众不知道事件是什么，说明桥梁喧宾夺主。
- 影视桥梁不能要求听众记得前情、角色关系或大结局，不能让“看过这部剧”成为理解后文的入场券。

可用的认知翻转包括：

- 影视把决定归给人物A，史料却显示人物B推动，或记录根本不能确定；
- 影视把冲突写成私人恩怨，史料显示真正约束来自继承、财政、军事或程序；
- 影视给出明确凶手或动机，史料只能支持多种假说；
- 影视用一场慷慨陈词解决问题，史料中的转折其实来自一份文书、门禁、证词或利益分配。

## 全片用量与回收

单篇一小时以内的口播只按叙事需要使用少量短桥梁；数量不随片长机械增加，也不设必须达到的配额。开场作品在正文相关证据处至少回收一次：明确哪部分是合理压缩，哪部分是戏剧改编，哪条史料让观众改变判断。不要把全片写成影视吐槽或逐集纠错。

每个桥梁进入`hook-ledger.json`，记录：作品与场景、观众原有判断、史料反差、首次兑现段、最终回收段、影视来源ID、历史主张ID和版权处理状态。

## 版权与视觉边界

- 口播可点名作品、人物并用自己的话简述必要场景；不复制长台词、长剧情或标志性段落。
- 实际使用剧照、正片片段、海报、配乐或演员肖像前，另做来源和许可审核。能在口播中提及，不等于能把画面放进成片。
- 没有明确使用权时，用本片原创手绘场景表达“戏剧化印象”和“史料反转”，不仿演员脸、不重建原剧镜头构图。
- 影视桥梁不是调用视频生成模型的授权；需要生成动态素材时仍遵守项目视频确认关卡。

## 交稿前检查

- 作品确实包含所述场景，作品名、人物与场景没有串台；
- 第一朗读段不是D级影视参照，定场在作品名之前已经完成；
- 第一朗读段已报题，紧接的内容能够用白话回答“这个题目说的是什么”；
- D段有`screen_reference`来源，F/Q/I段只由历史来源支持；
- “真实情况”没有把争议材料写成定论；
- 没看过该作品的人仍能复述事件、反差和主问题；
- 对比在短时间内回到本片因果链，没有展开成剧情回顾；
- 文字提及和实际画面使用的版权状态分开记录。
