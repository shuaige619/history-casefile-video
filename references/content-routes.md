# Content Routes

Choose one primary route and at most one secondary route. Preserve the shared evidence and hook rules, but do not force all topics into the same plot.

## Judicial miscarriage

Use for wrongful conviction, disputed trial, corruption investigation, or forensic reversal.

Required chain:

`incident → suspicion → evidence/procedure error → manufactured certainty → failed review → resistance → new evidence → decisive re-examination → personal and institutional consequences`

Primary question: Is there still a path to correction?

Required climax: decisive evidence, testimony, or procedure—not merely an emotional speech.

## Mass panic

Use for witch hunts, rumors, persecutions, moral panics, or security scares.

Required chain:

`local rumor → self-protection → horizontal persecution → official incentive → central politicization → expansion → contradictions → systemic exposure → scapegoating and cost`

Primary question: How can a disaster grow without a real conspiracy?

Show bottom-up fear and top-down incentives. Do not invent a hidden mastermind when the mechanism is distributed.

## Unresolved disaster or mystery

Use for explosions, disappearances, disputed causes, unexplained deaths, or archaeological mysteries.

Required chain:

`anomaly inventory → source and scene boundary → historical context → contemporary explanations → hypothesis list → evidence for/against → probability ranking → explicit uncertainty → consequences`

Primary question: Which explanation best fits the surviving evidence?

Never convert a disputed hypothesis into a factual verdict for dramatic payoff.

## Power purge

Use for court struggles, confiscations, factional collapse, coups, or posthumous rehabilitation.

Required chain:

`power peak → apparent protection → loss of power → alliance repositioning → accusation cascade → family/policy cost → beneficiary map → state-capacity damage → later reassessment → institutional paradox`

Primary question: Who drove the purge, who benefited, and what did the system lose?

Avoid reducing every actor to loyalist or villain. Track incentives and constraints.

## Historical character arc

Use for a life phase organized around repeated decisions rather than a single case.

Required chain:

`inherited problem → quantified constraints → attempt → failure → review → adapted attempt → internal obstacle → final irreversible choice → cost → legacy`

Primary question: What did the person choose when victory became unlikely?

Keep biography selective. Every episode must change the character's available options.

## War or state crisis

Use for battles, invasions, mutinies, state collapse, or military disasters.

Required chain:

`strategic situation → measurable constraints → command objective → opposing plans → first contact → turning decision → battlefield reversal → immediate losses → political consequences → counterfactual limits`

Primary question: Which constraint and decision produced the turning point?

Separate later legend from contemporary records. Maps must distinguish known troop movement from reconstruction.

## Hybrid routing

Use a secondary route only when it controls a substantial section. Examples:

- mass panic + power purge;
- unresolved mystery + judicial miscarriage;
- character arc + war crisis.

Do not alternate templates mechanically. Build one causal spine, then use the secondary route to clarify a specific phase.
