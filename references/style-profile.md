# 白话历史说书结构

这是原创建作的结构指南，不是模仿某位作者的逐句模板。

## 主线

`让人认识事件 → 一个具体疑问 → 人物所知与所怕 → 行动改变局面 → 新证据/约束 → 不可逆的选择 → 代价 → 回答开头`。

章节顺序服从理解和证据，不必机械分“背景、经过、意义”。每章应有一个明确任务，例如解释为什么援军未到、谁改变了消息、证据为何失去复核机会。未解之谜可以保留未解，不为了收尾制造确定结论。

## 钩子与兑现

- 开头直接用人物身份／事件关系与具体行动或有据异常形成钩子，让陌生听众听懂讲谁及为何继续听；默认不单独读正式标题，不插栏目招呼。题目与钩子方向一致，但分别自然表达，随后尽快开始局部兑现。
- 若使用影视记忆，先完成报题、解题和最小定场；作品名随后进入，不让听众靠预存剧情补背景。
- 转折来自新的事实、限制、判断或选择；不要靠反复“但万万没想到”。
- 经常让观众的理解发生变化，但不按固定秒数强塞一个反问。
- 章末的问题由下一章真正接续；大钩子在结尾由证据链回收。
- 不隐瞒观众理解当前行为必需的背景来制造悬念。

## 说人话

主语清楚，动词具体。先说“消息送不进去”，需要时再概括为“信息通道出了问题”。有长短句和留白，不把全文切成等长的短句。

适度语气词、反问、轻微冷幽默和熟悉作品的类比只能帮助理解；删除语气词后，人物动机与因果依然要清楚。悲剧处克制，不拿受害者受苦开玩笑。

旁白字数是策划参考，不是硬性速度指标。优先继承当前项目时长规则；AI写作工作区要求完整自然内容严格超过25分钟、不超过60分钟，25分钟整不通过，不要求写满。先按题材与证据确定有效容量，文本按项目格式检查估算上下界，音频阶段再以完整音轨实测；补写须提供新行动、证据或解释，不靠重复或空白凑长度；不把参考视频的ASR语速、句长或疑问词频当成必须追平的指标。

## 证据表达

短引文带出处，随后用白话解释其对当前判断的作用。区分记载、后世解释、争议、反事实和象征性示意。“后来”不自动等于“因此”，官方态度改变不自动证明证物真假，梦境转述不画成神灵实际显现。完整核验留在研究材料；口播中每次对读须改变当前理解，并接回行动或答案。具体取舍和开头独立理解检查见[白话口播](conversational-history-voiceover.md)，不以引用次数替代叙事评审。

## 结尾

先交代人和事的落点，再解释本片特有的机制与代价。可以回到开头的诏书、门、道路或选择，但用新的构图或后果视角，不重复播放旧素材。不要套用任何题目都能成立的励志或历史教训。
